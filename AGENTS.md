# AGENTS.md

Before implementing anything in this repo, read [docs/agents/architecture.md](docs/agents/architecture.md) and the
topic doc it links for the area you are changing. Check [docs/agents/features.md](docs/agents/features.md) before
adding a capability, because the gap may be deliberate. Verify your change with the gates in
[docs/agents/testing.md](docs/agents/testing.md).

Building a *different* app from this one? Follow [docs/reference/](docs/reference/README.md) instead.

When a change makes any of these docs untrue, update the doc in the same change.
